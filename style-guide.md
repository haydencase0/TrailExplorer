# Idaho Trail Explorer — Style Guide

## Color palette

Palette built and contrast-checked using Coolors.co.

| Role | Color | Hex | Notes |
|---|---|---|---|
| Primary | Deep pine green | `#2D4A3E` | Header, nav bar, footer |
| Secondary | Burnt rust orange | `#C1622D` | Active tab, primary buttons, key actions |
| Accent | Muted sky blue | `#7FA8B3` | Section labels, links, map elements |
| Background | Warm off-white | `#F7F5F0` | Main page background |
| Text | Slate gray | `#4A4F4D` | Body copy |

### Contrast and readability

- Slate gray text (`#4A4F4D`) on the off-white background (`#F7F5F0`) passes WCAG AA for normal body text.
- Off-white text (`#F7F5F0`) on the pine green header (`#2D4A3E`) passes WCAG AA for both normal and large text.
- Rust orange (`#C1622D`) is used only for buttons and accents, paired with off-white text, which keeps contrast strong since it's never used for long passages of body copy.
- Sky blue (`#7FA8B3`) is reserved for small labels and links rather than body text, since on its own it sits closer to the AA minimum for smaller font sizes.

## Typography

| Use | Font | Source | Weight |
|---|---|---|---|
| Heading | Fraunces | Google Fonts | 600 (semi-bold) |
| Body | Inter | Google Fonts | 400 regular, 500 medium |

### Why these fonts

- Fraunces is a slab serif with character, used for the site title and trail names. It's distinctive without being decorative or hard to read.
- Inter is a clean, neutral sans-serif used for body copy, labels, and UI text, including form fields and buttons. It stays legible at small sizes on mobile.
- Neither font is Times New Roman.

### Sizing for consistency

| Element | Font | Size | Weight |
|---|---|---|---|
| Page title | Fraunces | 22px | 600 |
| Section heading | Fraunces | 18px | 600 |
| Body text | Inter | 14–16px | 400 |
| Labels / small UI text | Inter | 11–12px | 500 |
| Button text | Inter | 13–14px | 500 |
